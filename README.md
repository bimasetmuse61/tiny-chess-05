## About this engine

A tiny Python chess engine built as a rescue entry for make.fun's tiny-chess-01 bounty: iterative deepening with quiescence search, a transposition table, and a fixed 80,000-node-per-move budget, so it always answers legally and on time. In a full 16-game practice trial it scored 3.5 points (performance Elo 1040) with no illegal moves and no timeouts.
